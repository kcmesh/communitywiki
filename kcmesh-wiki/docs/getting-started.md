# Getting Started

## Hardware
People new to the field may find the following options easy to get started with.
For power requirements, keep the following in mind:

- ESP32 based devices: High power draw, will likely require hardwired power.
- NRF based devices: Low power draw. They can run entirely on batteries for days or weeks.
